02How to deploy

Two ways in. Both free.

Install the ready-made app and start calling, or take the AL source into your own project.

Option 1

Install the app

  1. Download the .app and upload it in Business Central: Extension Management → Manage → Upload Extension. No dependencies, no setup page. It uses object IDs 90800–91099.
  2. Give the integration user OCPF - READ (every endpoint, GET) or OCPF - READ/WRITE (adds POST, PATCH and DELETE on the 135 editable endpoints), plus the standard permissions on the underlying tables.
  3. Authenticate with OAuth 2.0 and call any entity under the /v3.1/ base URL.
Latest .app · v3.1.4.0Getting Started guide
api.businesscentral.dynamics.com
# Base URL (replace the placeholders)
https://api.businesscentral.dynamics.com/v2.0/{tenantId}/{environment}
  /api/OnlyCopilotFans/ocpf_masterData/v3.1

# List customers
GET {base}/companies({companyId})/ocpfCustomers

# Filter, select, page
GET {base}/companies({companyId})/ocpfItems
    ?$filter=inventory gt 0&$select=no,description,inventory&$top=50

# Create a customer (OCPF - READ/WRITE)
POST {base}/companies({companyId})/ocpfCustomers
{ "no": "C-1001", "name": "Contoso Ltd." }
Option 2

Take the AL source

  1. Download one or more of the AL files from the GitHub repository. The API pages live in one folder per category: AccessControl, CoreFinancial, Manufacturing, MasterData, ProjectsAndAssets, Purchasing, Sales, ServiceManagement, SystemAndSetup; the two permission sets are in Permission Sets.
  2. Drop them into your own extension as they are, or extend them with your custom fields. Each page is a plain AL object with no dependency on the others.
  3. Renumber the object IDs into your own range if 90800–91099 collides with something you already have.
