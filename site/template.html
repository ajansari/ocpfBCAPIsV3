02How to deploy

Two ways in. Both free.

Install the ready-made app and start calling, or take the AL source into your own project.

Option 1

Install the app

  1. Download the .app and upload it in Business Central: Extension Management → Manage → Upload Extension. No dependencies, no setup page. It uses object IDs {{ID_FROM}}–{{ID_TO}}.
  2. Give the integration user OCPF - READ (every endpoint, GET) or OCPF - READ/WRITE (adds POST, PATCH and DELETE on the {{EDITABLE}} editable endpoints), plus the standard permissions on the underlying tables.
  3. Authenticate with OAuth 2.0 and call any entity under the /v{{API_VERSION}}/ base URL.

Option 2

Take the AL source

  1. Download one or more of the AL files from the GitHub repository. The API pages live in one folder per category: {{AL_FOLDERS}}; the two permission sets are in Permission Sets.
  2. Drop them into your own extension as they are, or extend them with your custom fields. Each page is a plain AL object with no dependency on the others.
  3. Renumber the object IDs into your own range if {{ID_FROM}}–{{ID_TO}} collides with something you already have.
