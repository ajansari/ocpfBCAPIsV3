01Install

Download the app. Upload it to Business Central. Assign a permission set.

One .app file, no dependencies, no setup page. Works on Business Central {{BC_VERSION}} and later, in any localization.

Download the appv{{APP_VERSION}} · .app

Install it in a sandbox first. The source is on GitHub if you prefer to build it yourself.

Step 1

Upload the extension

In Business Central, search for Extension Management, choose Manage → Upload Extension, pick the .app file, accept the terms and deploy. It takes a few minutes.

Step 2

Assign a permission set

Give the integration user OCPF - READ (every endpoint, GET) or OCPF - READ/WRITE (adds POST, PATCH and DELETE on the {{EDITABLE}} editable endpoints), plus the standard permissions on the underlying BC tables.

Step 3

Call an endpoint

Authenticate with OAuth 2.0 (Microsoft Entra app registration) and GET any entity under the /v{{API_VERSION}}/ base URL. The Getting Started guide has the full URL pattern and examples.

api.businesscentral.dynamics.com
# Base URL (replace the placeholders)
https://api.businesscentral.dynamics.com/v2.0/{tenantId}/{environment}
  /api/OnlyCopilotFans/ocpf_masterData/v{{API_VERSION}}

# List customers
GET {base}/companies({companyId})/ocpfCustomers

# Filter, select, page
GET {base}/companies({companyId})/ocpfItems
    ?$filter=inventory gt 0&$select=no,description,inventory&$top=50

# Create a customer (OCPF - READ/WRITE)
POST {base}/companies({companyId})/ocpfCustomers
{ "no": "C-1001", "name": "Contoso Ltd." }

# Discover every entity and field in a category
GET {base}/$metadata

Permission sets included

OCPF - READ covers all {{TOTAL}} endpoints. OCPF - READ/WRITE covers the {{EDITABLE}} editable ones.

Consumers also need the matching permissions on the base tables. The four Access Control endpoints additionally require SUPER or SECURITY to assign permission sets.
